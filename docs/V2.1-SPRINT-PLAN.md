## 1. How to use this plan

### Build conversation

Copy this into a new Agent-mode conversation:

```text
Implement exactly one sprint from docs/V2.1-SPRINT-PLAN.md.
Sprint ID: <e.g. S03>
Do not start any other sprint.
Start from the frozen SHA named in that sprint.
Do not inspect or copy the Astra branch.
Do not merge to main.
Do not publish.
Keep the current ChatGPT / Claude / Grok card language.
No Basic Mode. No UI redesign.
When the sprint’s tests pass (or the sprint is honestly BLOCKED),
write the Stage Report in the format in §33 of V2.1,
commit, push, open/update the draft PR, and STOP.
```

### Review conversation

Copy this into a separate conversation after the build PR exists:

```text
Independent review of sprint <e.g. S03> only.
Read docs/V2.1-SPRINT-PLAN.md for that sprint’s required tests and exit criteria.
Review the diff, the new tests, and the stage report.
Do not implement the next sprint.
Verdict must be PASS / FAIL / HOLD / BLOCKED.
If FAIL, list the exact tests or spec clauses that failed.
```

### Hard rules for every sprint

- One sprint, one conversation, start to finish.
- Do not “helpfully continue” to the next sprint.
- Do not weaken a test to make CI green.
- Do not treat cookie-exists / navigation-finished / WKWebView READY as recovery success.
- Do not add Basic Mode, public-rule-only mode, manual hit, estimated quota, or fabricated `resetAt`.
- Do not add Cursor / Gemini menu cards unless that provider’s Stage 6 sprint is PASS.
- Copilot is architecture benchmark only. No Copilot UI.
- Codex is not a sixth provider unless S01C proves the meter is different.
- Do not read chats, prompts, repos, or conversation history.
- TRUE BLOCKER → stop and report. Do not guess.
